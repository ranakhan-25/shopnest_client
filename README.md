# ShopNest Client

ShopNest is a modern e-commerce frontend application built with Next.js, TypeScript, Tailwind CSS, and Zustand.

## 🚀 Live Project

- Live Link:[ https://shopnest-five-theta.vercel.app](https://shopnest-five-theta.vercel.app)


---

## 🛠️ Technologies Used

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- Zustand
- HeroUI
- Gravity UI Icons
- Lucide React
- Framer Motion
- Axios / Fetch API
- JWT Authentication
- Vercel

---

## ✨ Features

### 👤 Authentication

- User registration
- User login
- JWT access token authentication
- Refresh token support
- Protected routes
- Role-based navigation
- Automatic session handling
- Logout functionality

### 🛍️ Products

- View all products
- Product details
- Product search
- Product filtering
- Product sorting
- Pagination
- Product categories
- Product stock status

### ❤️ Wishlist

- Add product to wishlist
- Remove product from wishlist
- View wishlist products
- Wishlist count

### 🛒 Cart

- Add product to cart
- Remove product from cart
- Update product quantity
- View cart
- Cart item count
- Total price calculation
- Authentication-based cart handling

### 📦 Orders

- View orders
- Order details
- Order status
- Order history

### 👨‍💼 Dashboard

Different dashboards are available based on user role.

#### User

- Dashboard
- Orders
- Wishlist
- Profile
- Settings

#### Seller

- Dashboard
- Products
- Orders
- Customers
- Analytics
- Payments
- Settings

#### Admin

- Dashboard
- Products
- Orders
- Users
- Sellers
- Categories
- Analytics
- Settings

### 🎨 UI / UX

- Responsive design
- Mobile-friendly navigation
- Desktop sidebar
- Mobile drawer sidebar
- Dark mode
- Light mode
- Loading states
- Error states
- Empty states
- Responsive product cards
- Responsive tables
- Modern dashboard UI
